# 適用した教訓

- ACTIVE: ローカルmerge済みでもGitHubへpush済みとは限らない。切断後は双方のSHAを照合し、保存済みmergeと画像を再利用する。
- ACTIVE: 動いているmainが入力を撤回したとき、古いキャッシュを現在の原本へ戻さない。履歴identityと現在状態を別に記録してDRAFT表示へ反映する。
- ACTIVE: 自動overflow検査は不自然な日本語の列分割を見逃す。実画像を目視し、検査用の文分割と表示上の原文行グルーピングを分離する。
- ACTIVE: 1行に複数のイベント日付がある場合、最初の日付を全イベントへ適用しない。近接する前後の日付を解析し、曖昧な場合はUNKNOWN。CPI/PPI/小売の日付とDSTを負例で確認する。
- ACTIVE: 市場履歴にverifiedとあっても、対象cutoffを超える取得時刻や別スキーマは正規snapshotの代わりにならない。
