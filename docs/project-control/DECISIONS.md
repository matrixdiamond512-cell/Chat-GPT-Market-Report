### P1 connection contract (implementation boundary, not deployment authorization)

| Boundary | Required contract before adapter implementation/acceptance |
|---|---|
| Topology | Independent Cloud Scheduler → authenticated Cloud Run HTTP ingress → private shadow-only Cloud Storage bucket/prefix. Use HTTP service, not an ambiguously mixed Run Jobs invocation. No path to Docs, GitHub canonical/evidence/receipt or Pages. |
| Schedule | Asia/Tokyo, current config weekdays 08/12/16/21 only, attempts T-13/T-7/T-3. Allowlist each full Scheduler job resource name → fixed slot/offset/timezone. Validate its original scheduled timestamp against that mapping; actualStartedAt is audit-only, never a date source. Manual requests require a separate explicit identity route and remain shadow-only. |
| Authentication | Require Cloud Run IAM authentication with exact audience and dedicated invoker service account. Ingress verifies trusted OIDC issuer/signature/expiry/audience/allowlisted subject (or an explicitly documented equivalent trusted platform boundary), then validates job name/time mapping. Scheduler headers are metadata, not independent cryptographic proof; a token does not sign arbitrary header contents. Reject public/unauthenticated traffic and header-only claims. Limit who may impersonate the invoker. |
| Storage | EvidenceStore.create must use ifGenerationMatch=0 and translate 412 to FileExistsError/read-reconcile. Read exact generation, immutable bytes, SHA-256 and server metadata timestamp; do not treat client metadata as server time. Bind envelope schema, reportId, target, snapshot timestamp/hash and producer/source identity before calling EvidenceWriter; raw bytes alone do not prove market freshness. |
| Retry/concurrency | Same reportId+bytes → NO_OP; different bytes → CONFLICT; no overwrite/delete, even after uncertain upload response. Persist immutable evidence and stage records separately. Retry transport failures by reading/reconciling before create; never use process-local locks as distributed ownership. A new process uses the same store. Stage existence is no substitute for verified evidence. Official eligibility always false in this module. |
| Deadlines | Check T before/after evidence and stage writes/readbacks using fresh client time and storage server time. Timeout budget per request ≤120s and bounded by remaining time before T; no official late write/reconstruction. EXPIRED remains original identity for audit/draft-only decisions. |
| IAM/secrets | Dedicated invoker with only target roles/run.invoker; runtime with bucket-scoped create/get and no object update/delete; deploy operator separate. No provider key or OpenAI secret for P0/P1. Project, region, audience, service accounts, bucket, retention, allowed producer and cost ceiling remain REQUIRED INPUTS, not guessed values. |
| Operational handoff | Log reportId, scheduledAt, actualStartedAt, stage status, hash/generation/server time, retries and failure reason without credentials. Fixture success is not authenticated scheduler/storage proof. Define monitoring retention and conflict alert destination before any live run; no notifications sent here. |
| Cutover | First use an isolated nonproduction bucket and fixture payloads under explicit provisioning approval. Require real OIDC reject/accept cases, job/time spoof rejection, duplicate concurrent invocations across processes, 412 handling, upload-response loss, generation mismatch, T crossings, cold restart recovery and zero protected writes. Only then consider a separately approved production writer handoff/rollback. |
