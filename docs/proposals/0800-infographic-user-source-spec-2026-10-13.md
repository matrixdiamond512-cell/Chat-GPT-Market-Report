## 1. 修正目的

2026/10/12 08:00の図解は、16項目の情報を整理できている一方、2026/10/09 08:00版と比較すると、配色・視覚的強調・アイコン・市場間の因果関係の表現が弱くなっている。

主な問題は以下のとおり。

- 白背景のカードが多く、視覚的なメリハリが不足している
- 重要情報と補助情報の表示上の優先度がほぼ同じ
- ニュースと市場反応の関係が文章中心になっている
- クロスアセット資金フローを直感的に把握しにくい
- 6市場の強弱判断が目立たない
- 見出しの配色は異なるものの、本文の視覚構造が単調
- カード内の余白が大きい箇所と文字が密集する箇所が混在している

本改修では、既存の分析内容と情報量を維持しながら、2026/10/09版の鮮やかで情報を把握しやすいデザインを復活させる。

**最重要方針：データや分析ロジックは変更せず、表示テンプレートとレイアウト処理を改善する。**

## 5. 配色設計

### 5.1 基本パレット

| 用途 | 色 | 推奨カラー |
|---|---|---|
| 全体ヘッダー | 濃紺 | #091C58 |
| 通常パネル | ブルー | #0757BC |
| 市場上昇 | ピンク～赤 | #E91E63 |
| 市場下落 | ブルー | #0875E1 |
| 中立 | グレー | #738095 |
| 商品・原油のテーマ | オレンジ | #F26916 |
| 資金流入 | グリーン | #00A86B |
| 資金流出 | レッド | #DF3046 |
| リスク警戒 | 赤 | #D7263D |
| 重要結論 | イエロー | #FFC928 |
| 本文 | 濃紺 | #102652 |
| 本文背景 | 白～淡青 | #FFFFFF / #F1F7FF |

### 5.2 色の意味を固定

上昇・下落と、好材料・悪材料は別の概念として管理する。

上昇：ピンク・赤系  
下落：ブルー系  
横ばい：グレー系

資金流入：グリーン  
資金流出：レッド

注意・警戒：赤  
結論の強調：黄色

たとえば原油価格が上昇した場合、原油の価格変化はピンク・赤系で表示する。ただし、その上昇が株式市場にとって悪材料である場合は、株式への波及を警戒色で表示する。

色の選択を単なる「良い・悪い」の主観で決めない。

### 5.3 カラーコードの集中管理

配色定義は可能な限り共通のテーマ設定にまとめる。

ただし、他のレポート時刻やポータルの既存色が変わらないよう、08:00テンプレート専用の名前空間を使用する。

## 6. レイアウト改善

### 6.1 ヘッダー

- 2026/10/09版の大型濃紺ヘッダーを基準とする
- タイトルと日時を最も大きく表示する
- 今日の相場を一文でまとめたサブタイトルを追加する
- 作成基準時刻を明示する
- 背景イメージは視認性を妨げない範囲で使用する

### 6.2 重要4カード

No.01～04を最上段に配置する。

重要度に応じて、背景・数字・アイコン・余白の強弱をつける。

単純に4枚の白いカードを並べただけのデザインにはしない。

### 6.3 NY市場と主要指標

No.05～08は、時系列・終値・日本市場・金利等の4領域に分ける。

- NY時系列は段階別の帯・ラベルで表示
- 指数一覧は表形式
- 数値・前日比・騰落率を列で分離
- 上昇・下落色を統一
- 休場や時点の異なるデータには基準日時を付記する

### 6.4 クロスアセット資金フロー

No.09は従来の文章のみの表示から、資金移動が理解できる図解へ変更する。

基本構成：

左：資金流入が示唆される資産  
中央：資金移動を示す矢印  
右：資金流出が示唆される資産

ただし、重要な制約がある。

**価格上昇だけを根拠に実際の資金流入額を断定しない。**

ETFフロー・先物建玉・ファンドフロー等が取得できない場合は「市場反応からの推定」と明示する。

実測データと推定を視覚的にも区別する。

### 6.5 ニュース・材料と波及

No.10は、重要ニュースを単純に箇条書きするのではなく、

**ニュース → 直接影響を受ける市場 → 金利・為替への波及 → 株式・暗号資産への影響**

という因果関係を見せる。

因果関係が確認されていない場合は、確定的な矢印を使わず、「想定経路」「注目点」などの表現を用いる。

### 6.6 6市場見通し

No.13の6カードは統一したフォーマットにする。

各カード内に以下を表示する。

1. 市場名とアイコン
2. 現在値・基準時刻
3. 大きな方向表示
4. 判断根拠
5. 強気条件
6. 弱気条件

方向表示は価格の予測方向であり、売買推奨や確定的な予測と混同しない。

### 6.7 最下段

No.14～16は次の内容を明確に分離する。

- 次時間帯への引き継ぎ
- リスク管理
- 最終結論・データ検証

No.16では、結論とデータ取得状況を別の小領域に分離する。

検証済み・取得不能・公開不可の状態を混同させない。

## 7. アイコン・矢印

採用するアイコン：

- 国旗：米国、日本、欧州
- 金：金塊
- 原油：原油ドラム
- 株式：上昇・下落の矢印
- 金利：金融機関・金利記号
- 為替：通貨記号
- BTC：Bitcoin
- 警戒：警告マーク
- 重要：番号付き円形アイコン

装飾目的だけのアイコンは増やさない。

矢印は、方向判断・資金移動・因果関係のいずれを示すか明確にする。

## 8. 文字・情報密度

### 8.1 基本原則

情報量を減らして見た目を整えることは禁止する。

調整の優先順位は以下。

1. 不要な余白を減らす
2. カード内の配置を最適化する
3. 表示領域を再配分する
4. 適切な改行を入れる
5. 画像の縦方向を拡張する

文字サイズを無制限に小さくして解決しない。

### 8.2 禁止事項

- 文字切れ
- 見出しの欠落
- 内容の重複
- 重要条件の省略
- 数字の推測補完
- 画像生成による数値改変
- 不自然な日本語の省略
- 英語と日本語の意図しない混在
- 番号の重複や欠番

### 8.3 画像サイズ

既存の出力アスペクト比と利用先を確認する。

横幅は既存ポータルの表示領域に合わせる。

1枚に収まらない場合は、まず縦方向を拡張する。

768px幅での表示検査を必須とする。

スマートフォンで判読できない文字を大量に詰め込んで合格にしない。

### Phase 2：修正範囲の確定

変更対象ファイルを一覧化する。

変更が必要な理由と、既存機能に与える影響を確認する。

08:00以外のテンプレートは原則として変更しない。

### Phase 3：デザイン実装

第5章～第8章を反映する。

可能な限り、描画内容とテーマ設定を分離する。

### Phase 4：合成データによるテスト

まず合成fixtureで以下を確認する。

- 16項目が全部存在する
- 6市場が存在する
- 長いニュース見出しでも文字切れしない
- 正負の値が正しい色で表示される
- データ取得不能が正しく表示される
- 因果関係図がカード外にはみ出さない
- 上昇・下落と資金流入・流出が混同されない
- 768px幅でも最低限の可読性が確保される

合成fixtureを用いた画像にはDRAFTであることを明示する。

### Phase 5：実レポートによる検証

2026/10/09および2026/10/12の実レポートを使用する。

ただし、正規の検証済みレポート本文・構造化データ・snapshot等が存在する場合に限る。

参考画像からの数値再入力や、欠けている実市場データの推測補完は禁止する。

必要な入力契約を満たさない場合は、DRAFT生成や公開承認を既存品質ゲートに従って制限する。

### Phase 6：回帰テスト

以下を確認する。

- 既存の数値検証が維持される
- 本文と図解の一致検査が維持される
- 他時刻のレポートに影響がない
- 既存のDRAFT・公開判定が維持される
- 保存・ポータル連携が破損していない
- 変更対象外のテストが後退していない

既存テストが失敗している場合は、今回の変更によるものか切り分ける。

## 10. 合格基準

以下をすべて満たすことを正式な合格条件とする。

| 項目 | 合格条件 |
|---|---|
| 構成 | 固定16項目が欠落せず順序が正しい |
| 情報量 | 必須の分析内容が保持されている |
| デザイン | 10/09版の視覚的メリハリを再現 |
| 配色 | 上昇・下落・資金流入・流出を正確に区別 |
| 方向表示 | 6市場すべてに必要な方向判断を表示 |
| 因果関係 | ニュースから市場反応へのつながりが読み取れる |
| 文字 | 文字切れ・重なり・不自然な省略なし |
| 数値 | 元の検証済みデータと完全一致 |
| 出典時刻 | 異なる基準時点を混同しない |
| 検証 | 品質ゲートの回避なし |
| 回帰 | 変更範囲外の既存機能に新たな不具合なし |
| 公開管理 | DRAFTと承認済み成果物を区別 |

**画像が華やかになっただけでは合格としない。**

情報の正確性、分析内容の維持、視認性の3つがそろった場合のみ合格とする。
