# OpenAI APIマーケットレポート 自動生成・公開統合手順
更新：2026-10-15 JST。対象：PR #130。状態：開発中・非公開。

## 合格した範囲
- OpenAI API認証・モデル一覧取得。
- 2026-10-14 21:00の実市場価格で入力トークン数をAPIで計測。
- 1回限りの有料Responses API生成：応答 completed、3,517 input / 2,286 output、推定$0.01292475、本文2,009文字。
- ただし生成本文は誤曜日・強弱解釈・ニュース根拠不足があったため検証不合格、非公開。
- 新しい品質検査コード：d3_release_evidence.py、d3_narrative_quality.py、d3_report_candidate_review.py、d3_release_preflight_cli.py。模擬データのCI合格。合格しても自動公開権限は付与しない。

## 未完成の理由と実装優先順位
1. 08:00・12:00・16:00・21:00それぞれで発行時刻より前に取得した相場データを固定する。10月15日08:00用の日時別市場ファイルは確認できていない。
2. 最新ニュースの独立ソースから取得した本文と公表時刻を記録するアダプタを作る。ニュースに加え、金利・需給・CFTC・ETFフロー・先物建玉・イベントも発表日時と取得元、信頼性を記録し、各時刻の固定済み証拠に組み込む。取得不能を事実にすり替えない。
3. 朝8時は米株、CME日経先物、日経PER/EPS/PBR、騰落など朝レポート固有項目の証拠も必要。欠けた項目は現時点の証拠不足として明示する。
4. 市場データとニュース等の照合が通った時だけ、別途本人が承認した月間上限・個別発行上限・費用残高と照合し、OpenAI APIへ1回だけ送信する。タイムアウト時は重複課金を招く無断再試行を禁止。
5. モデル出力は数値監査・曜日・強弱方向・追加必須セクション・関連ニュースと値動きの整合性を検査する。結果が悪い場合は原本を捏造して補正せずBLOCKED。
6. producer署名済み証拠とGoogle Docs作成主体を連携する。現状サービスアカウントは閲覧者なのでGoogle Docs自動作成権限と所有権・保存経路は未検証。本文の作成と読み戻しまで完了してからGitHub公開する。
7. Github ActionsからChatGPTの特定会話へ自動投稿する経路は実装されていない。既存のChatGPT定時タスクを使う場合は、API生成された本文と同じハッシュの原本を読み、実際にチャットへ全内容を表示した事実を別途確認する。
8. ChatGPT本文表示、Google Docs読戻し、GitHub履歴、ポータルPages実画面の4つを時刻別に検証するまで定時公開は完了と呼ばない。
9. PR #130は公開ゲートに関する広範な未マージ変更を含み、現在のmainと合わせて回帰試験する必要がある。安全性を落とさずレビューしてから統合する。

## 費用・権限
- 以前の0.03米ドル承認は単発のモデル生成テストのみに適用。定時の有料API継続利用は未承認。
- APIキー等はGitHub Secretsで管理し、ログ・ソースに書き込まない。
- Google Docsからの読み取りとDocsへの新規作成は別の権限・機能。

## 無課金の具体的診断
「python -m scripts.reporting.d3_release_preflight_cli --date 2026-10-14 --slot 21:00 --market data/market/history/2026-10-14_21-00.json --diagnostic」
このコマンドはニュース・金利・需給・イベントの統合証拠が無いとBLOCKEDを返す。API送信はしない。

## ステータスの定義
- API認証成功 ≠ レポート生成成功
- AIモデルのcompleted ≠ 内容検証成功
- PRIVATE_DRAFT_VALIDATED ≠ Google Docs保存・公開成功
- 全工程の読戻しと本文表示の成功を確認して初めて完了
