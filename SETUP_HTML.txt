HTML版への切り替え手順

1. ZIPを展開します。
2. index.html、style.css、script.js、reports.json の4ファイルを、
   GitHub Desktopで作成した以下のフォルダへ上書きコピーします。

   C:\Users\Atsuk\Documents\GitHub\Chat-GPT-Market-Report\

3. imagesフォルダは不要です。残っていても問題ありません。
4. GitHub Desktopを開きます。
5. Summaryに次を入力します。
   Switch to HTML market reports
6. Commit to main を押します。
7. Push origin を押します。
8. 1～3分後、以下をCtrl+F5で再読み込みします。
   https://matrixdiamond512-cell.github.io/Chat-GPT-Market-Report/

このサンプルには市場の実数値を入れていません。
次回以降、確認済みのマーケットレポート本文をreports.jsonに追加して公開します。
